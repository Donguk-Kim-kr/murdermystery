머더미스터리 플랫폼

머더미스터리 시나리오를 만드는 제작 툴과, 완성한 작품을 같은 사이트에서 여럿이 함께 플레이하는 웹 플랫폼입니다. 제작 툴은 PC, 플레이는 PC와 모바일을 지원합니다.

저장소 엔진 명세 DB 규칙

무엇을 만들었나

  • 시나리오 제작 툴 — 인물·장소·단서·사건·엔딩을 순서와 무관하게 만들고 서로 연결합니다. 진행단계와 기믹은 라이브러리에 만들어 여러 작품에서 재사용하고, 확정하면 한 버전으로 굳어집니다.
  • 실시간 플레이 — 방 만들기·입장코드·대기실, 공통 스토리 → 캐릭터 선택 → 조사 → 토론 → 투표 → 엔딩으로 이어지는 진행, 전체·밀담 채팅, 방장 관전(GM/일반) 모드.
  • AI 플레이어 — Anthropic API로 일반 계정처럼 접속해 같은 API로 방에 들어와 게임을 합니다. API 키가 없으면 규칙 기반으로 대신 동작합니다.
  • 한 번에 실행 — docker compose up --build 한 줄로 앱과 DB를 올리고, 시연용 샘플 작품(「동짓날 마을회관」, 4인)이 자동 등록됩니다.

기술적으로 신경 쓴 부분

제작자 스크립트를 안전하게 실행하는 해석기

제작자가 쓰는 기믹은 파이썬 문법의 제한된 부분집합입니다. exec/eval을 쓰지 않고 허용한 구성만 직접 해석하며(compiler 약 380줄, vm 약 390줄), 실행 위치·변수·호출 구조를 데이터로 들고 있어 플레이어 입력을 기다렸다가 이어서 실행합니다.

backend/app/script/

보는 사람별로 서버가 걸러 내려주는 정보

머더미스터리는 사람마다 아는 정보가 다릅니다. 화면에서 숨기는 것이 아니라 서버가 보는 사람(플레이어·GM 관전·일반 관전)에게 허용된 것만 응답에 담습니다. 밀담 기록은 받는 사람만 볼 수 있습니다.

backend/app/visibility.py · chat.py

SQL 직접 작성 + 마이그레이션 체크섬

ORM 없이 psycopg 3로 SQL을 직접 씁니다. 적용된 마이그레이션 파일이 바뀌면 실행기가 중단되도록 체크섬을 검사하고, 제약·트리거·격리를 DB 단에서 시험합니다.

db/migrations/ · db/tests/

OpenAPI에서 프론트 타입 자동 생성

FastAPI의 API 명세에서 TypeScript 타입을 생성해(npm run gen:api) 백엔드가 바뀌면 프론트 빌드가 타입 오류로 알려 줍니다.

frontend/src/api/schema.d.ts

실시간 갱신은 SSE

WebSocket 대신 SSE를 써서 통신을 HTTP 안에 두었습니다. 조각난 스트림을 이어 붙이는 파서를 따로 두고 시험합니다.

backend/app/game.py · frontend/src/game/sse.ts

실제 브라우저로 한 판을 끝까지

Playwright로 브라우저 3개(PC 2, 모바일 폭 1)가 공통 진행단계 12개를 끝까지 플레이합니다. 같은 인물 동시 선택, 자기 서사만 보이는지, 비공개 투표 등을 확인합니다.

한계와 앞으로의 과제

  • 대기실의 입장자 목록이 서버 메모리에 있어 서버 프로세스를 하나로만 실행해야 합니다(수평 확장 불가).
  • 배포하지 않았고, docker-compose.yml의 비밀번호는 개발용입니다. 인터넷에 공개할 수 있는 상태가 아닙니다.
  • 불특정 다수 매칭은 구현하지 않았습니다(지인끼리 플레이 전제).
  • 3D 연동, 공개 작품 노출·위시리스트, 관리자 화면 등은 보류 중입니다(docs/BACKLOG.md).
