# 시연용 미디어 폴더

이 폴더의 이미지·영상은 `docker compose up` 으로 켤 때 샘플 작품 「동짓날 마을회관」을 **처음 만들면서** 자동으로 붙는다.
이미 만들어진 샘플 작품(데이터 볼륨이 남아 있는 경우)에는 붙지 않는다. 그럴 때는 `docker compose down -v` 로 데이터를 지우고 다시 켜거나,
제작 화면에서 직접 올린다.

## 파일 이름 규칙

| 파일 이름 | 붙는 곳 | 형식 |
|---|---|---|
| `인물-황칠성.jpg` | 이름이 황칠성인 인물의 캐릭터 이미지(캐릭터 선택 카드) | jpg·png·webp, 5MB 까지 |
| `단서-찢어진 편지.png` | 이름이 찢어진 편지인 단서의 이미지(그 단서를 얻은 사람의 내용 카드 안) | jpg·png·webp, 5MB 까지 |
| `공통스토리.mp4` | 공통 스토리 영상(공통 스토리 단계) | mp4(H.264), 100MB 까지 |
| `표지.png` | 작품 표지 이미지(플레이 첫 화면의 작품 카드) | jpg·png·webp, 5MB 까지(세로 2:3 비율을 권장) |

* `인물-` 과 `단서-` 뒤에는 샘플 작품에 있는 **정확한 이름**을 쓴다(인물: 오태훈, 황칠성, 한유진, 정막례. 단서 이름은 제작 화면의 조사 탭에서 확인한다).
* 이름이 맞지 않거나 형식이 다른 파일은 건너뛰고, 켤 때 로그에 "건너뜀" 으로 나온다.
* 이 파일(README)처럼 이미지·영상이 아닌 파일은 무시한다.
* 같은 인물·단서에 파일을 여러 개 두면 마지막(이름순) 파일 하나만 남는다.

사용자가 ChatGPT 로 만든 이미지 13장(webp)이 들어 있다. 이미 만든 샘플 작품에는 붙지 않으므로 `docker compose down -v` 뒤에 다시 켜야 한다.

* 표지(세로 2:3): `표지.webp` — 제목 글자가 들어간 그림
* 인물 4장(정사각형): `인물-오태훈.webp`, `인물-황칠성.webp`, `인물-한유진.webp`, `인물-정막례.webp`
* 단서 8장(가로 4:3): `단서-` 뒤에 샘플 작품의 단서 이름(마당의 발자국, 이장의 장부 마지막 장, 팥죽 배식 당번표, 피 묻은 무쇠 부지깽이, 한유진의 가방 속 메모, 혈흔이 묻은 배식용 면장갑, 황칠성의 담뱃갑, 황칠성의 통화 기록)
* 공통 스토리 영상(`공통스토리.mp4`)은 아직 없다.
