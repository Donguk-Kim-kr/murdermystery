# 백로그 (아직 만들지 않기로 한 기능)

사용자가 "나중에"로 미룬 항목과 그 이유·전제. 결정이 아니라 메모이다.

| 항목 | 내용 | 미루는 이유 / 전제 |
|---|---|---|
| 위시리스트·플레이리스트 | 사용자별로 작품을 담아 두는 목록 | 담을 작품을 보여 주는 **공개 작품 목록이 보류**(사용자 결정)라서 화면이 없다. 새 테이블이 필요하다(예: 계정·작품·종류·추가일시, UNIQUE(계정, 작품, 종류)) |
| 플레이한 게임 숨기기 | 플레이 기록이 있는 작품은 작품 목록에서 안 보이게 | 위와 같은 이유 + **플레이 기록**(방·참여 기능)이 아직 없다. 기록은 `참여`→`진행`→작품으로 조회할 수 있어 새 컬럼은 필요 없을 가능성이 높다. 사용자가 다시 보고 싶을 수 있으므로 켜고 끄는 선택이 필요해 보인다(미확정) |
| 관리자 화면 | 권한 지정, 방 강제 폐쇄, 작품 비공개 처리 | 관리자 페이지를 따로 만들 예정(사용자 결정). 비공개 처리 API 는 이미 있다(`publishing.py`) |
| 확정 전 검증 툴 | 논리·스토리 검증 후에만 확정·공개 | 검증 방식 미확정(사용자 결정). 공개 조건(B10)은 이 기능과 함께 `ensure_can_publish()` 에 넣는다 |
| 운영자 고유 권한 | 운영자만 할 수 있는 일 | 사용자가 나중에 정하기로 함 |
| 비공개 작품 방 생성 권한 위임 | 제작자가 다른 사람에게 비공개 작품의 방 생성 권한을 줌 | 필요 여부 미정. 필요하면 `테스터`(현재 입장 권한 용도로 만들었으나 B37 로 불필요)를 이 용도로 바꾸거나 제거 |
