# 백로그 (아직 만들지 않기로 한 기능)

사용자가 "나중에"로 미룬 항목과 그 이유·전제. 결정이 아니라 메모이다.

| 항목 | 내용 | 미루는 이유 / 전제 |
|---|---|---|
| 위시리스트·플레이리스트 (같은 기능) | 사용자별로 작품을 담아 두는 목록 | 담을 작품을 보여 주는 **공개 작품 목록이 보류**(사용자 결정)라서 화면이 없다. 새 테이블이 필요하다(예: 계정·작품·종류·추가일시, UNIQUE(계정, 작품, 종류)) |
| 플레이한 게임 숨기기 | 플레이 기록이 있는 작품은 작품 목록에서 안 보이게 | 위와 같은 이유 + **플레이 기록**(방·참여 기능)이 아직 없다. 기록은 `참여`→`진행`→작품으로 조회할 수 있어 새 컬럼은 필요 없을 가능성이 높다(`진행`에는 계정이 없어 `참여`를 거쳐야 하고, 대기실만 다녀간 입장자는 DB에 기록되지 않는다). 사용자가 다시 보고 싶을 수 있으므로 켜고 끄는 선택이 필요해 보인다(미확정) |
| 관리자 화면 | 권한 지정, 방 강제 폐쇄, 작품 비공개 처리 | 관리자 페이지를 따로 만들 예정(사용자 결정). 비공개 처리 API 는 이미 있다(`publishing.py`) |
| 확정 전 검증 툴 | 논리·스토리 검증 후에만 확정·공개 | 검증 방식 미확정(사용자 결정). 공개 조건(B10)은 이 기능과 함께 `ensure_can_publish()` 에 넣는다 |
| 운영자 고유 권한 | 운영자만 할 수 있는 일 | 사용자가 나중에 정하기로 함 |
| 제작자 글꼴 (작품·플레이 화면용) | 사이트가 검수해 등록한 **공용 글꼴 카탈로그**에서 제작자가 작품 테마의 글꼴을 고르고, 즐겨찾기로 자주 쓰는 글꼴을 먼저 보여 줌 | 방향은 결정(2026-10-14), 설계는 미착수. 아래 "글꼴 메모" 참고. 작품 테마 설정 형식은 JSONB 형식 논의와 함께 정한다 |

## 글꼴 메모 (2026-10-14 대화)

- **구조**: 작품별 글꼴 테이블이 아니라 전체 공용 카탈로그 1개(이름, 파일 경로, 라이선스 종류, 출처, 검수자, 검수일시, 상태) + 계정별 즐겨찾기. 계정별 보관함은 두지 않는다. 즐겨찾기는 위시리스트와 함께 설계하는 안.
- **라이선스로 글꼴을 내릴 때(결정)**: 운영자의 비공개(사용 중단) 설정을 적용한다. 항목은 지우지 않고 사용 중단 상태로 바꿔 새 선택을 막고, 이미 확정된 작품에서는 기본 글꼴(Pretendard)로 대체해 보여 준다. 운영자만 되돌릴 수 있다는 구조는 작품 공개(B35)와 같다.
- **등록 기준**: 상업 사용 · 웹 임베딩 · 파일 재배포가 모두 허용되는 글꼴(OFL 등). "상업 사용 가능"만으로는 부족하다. 검수 절차는 필요(결정). 검수 자동화 방식은 나중에 고민 — 신뢰할 수 있는 출처(`@fontsource` 등 패키지 메타데이터에 라이선스가 표기됨)에서만 가져오는 반자동 방식이 후보.
- **미정**: 제작자가 개인적으로 구매한 글꼴을 자기 작품에 쓰게 할지. 주의: 플레이 화면에서 쓰려면 다른 참여자의 브라우저가 글꼴 파일을 받아야 하므로 "자기 작품에만 적용"이어도 웹 임베딩 허용 여부(웹폰트 라이선스)가 걸린다. 사이트가 소유 여부를 검증할 수 없다. 추가 논의 필요.
- **글꼴 파일**: 한글 글꼴은 글자 범위별로 쪼개 필요한 조각만 내려받는다(앱 글꼴 Pretendard가 이 방식: 92조각 중 로그인 화면은 6조각, 153KB).
- **앱 글꼴 설정**: Pretendard `ss05`(부호를 한글 높이에 맞춤)를 전체에 적용했다. 렌더링 비교로 효과를 확인했다.
